# 配方管理系统

一个用于管理 Minecraft 模组配方的可视化工具，支持物品、标签、配方管理及配方树可视化。

## 功能特性

- **物品管理**：创建、编辑、搜索物品，查看物品所属标签
- **标签管理**：支持标签嵌套，子标签物品自动同步到父标签
- **配方管理**：支持工作方块、输入、附加、输出槽位，支持标签/多物品
- **高级搜索**：按工作方块、输入、附加、输出筛选配方
- **配方树可视化**：查看物品的获取路径或用途，支持缩放、拖拽
- **数据自动保存**：所有数据存储在浏览器 LocalStorage，无需后端

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

访问 http://localhost:5173

### 构建生产版本

```bash
npm run build
```

构建完成后，直接打开 `dist/index.html` 即可使用（纯静态，无需服务器）。

## 使用说明

### 物品管理

1. 点击"物品管理"标签页
2. 点击"+ 新建物品"创建物品
3. 填写显示名称和 Minecraft ID
4. 点击物品可编辑或查看快捷操作

### 标签管理

1. 点击"标签管理"标签页
2. 点击"+ 新建标签"创建标签
3. 添加物品到标签（支持搜索）
4. 添加子标签（子标签的物品会自动同步到父标签）

### 配方管理

1. 点击"配方管理"标签页
2. 点击"+ 新建配方"创建配方
3. 选择工作方块
4. 添加输入/附加/输出槽位（支持物品或标签）
5. 点击"高级筛选"可按工作方块、输入、附加、输出搜索

### 配方树

1. 点击"配方树"标签页
2. 搜索并选择目标物品
3. 选择模式：
   - **查看获取**：显示如何制作该物品（原料 → 成品）
   - **查看制作**：显示该物品的用途（原料 → 衍生物）
4. 点击"生成配方树"
5. 使用鼠标拖拽、滚轮缩放查看

### 快捷操作

- 点击任意物品/标签可弹出快捷菜单
- 右上角"显示ID"开关可切换是否显示 Minecraft ID
- 配方树支持 Ctrl+滚轮缩放，Shift+滚轮平移

## 数据导出/导入

数据存储在浏览器 LocalStorage 中，可通过以下方式备份：

1. 打开浏览器开发者工具（F12）
2. 进入 Console 标签
3. 导出数据：
   ```javascript
   copy(localStorage.getItem('recipe_manager_data'))
   ```
4. 导入数据：
   ```javascript
   localStorage.setItem('recipe_manager_data', '粘贴你的数据')
   location.reload()
   ```
