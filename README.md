# 配方管理系统

用于管理 Minecraft 模组物品、标签、配方、价格与配方树的可视化工具。

公开只读网站：[https://yinfires.github.io/recipe-manager/](https://yinfires.github.io/recipe-manager/)

## 功能特性

- **物品管理**：创建、编辑、搜索物品，查看物品所属标签
- **标签管理**：支持标签嵌套，子标签物品自动同步到父标签
- **配方管理**：支持工作方块、输入、附加、输出槽位，支持标签/多物品
- **高级搜索**：按工作方块、输入、附加、输出筛选配方
- **拼音搜索**：所有名称搜索均支持中文、连续全拼和拼音首字母
- **配方树可视化**：查看物品的获取路径或用途，支持缩放、拖拽
- **文件化数据**：本地编辑模式自动保存到仓库 JSON，生产网站读取只读快照

## 快速开始

### 安装依赖

```bash
npm install
```

### 开发模式

```bash
npm run dev
```

访问 http://localhost:5173

### 构建生产版本

```bash
npm run build
```

构建完成后，直接打开 `dist/index.html` 即可使用（纯静态，无需服务器）。

### 发布公开快照

推送 `master` 分支后，GitHub Actions 会自动执行测试、构建并发布到 GitHub Pages。首次发布前，需要在仓库 `Settings → Pages` 中将发布来源设为 `GitHub Actions`。测试或构建失败时不会替换当前线上版本。

## 使用说明

### 物品管理

1. 点击"物品管理"标签页
2. 点击"+ 新建物品"创建物品
3. 填写显示名称和 Minecraft ID
4. 点击物品可编辑或查看快捷操作

### 标签管理

1. 点击"标签管理"标签页
2. 点击"+ 新建标签"创建标签
3. 添加物品到标签（支持搜索）
4. 添加子标签（子标签的物品会自动同步到父标签）

### 配方管理

1. 点击"配方管理"标签页
2. 点击"+ 新建配方"创建配方
3. 选择工作方块
4. 添加输入/附加/输出槽位（支持物品或标签）
5. 点击"高级筛选"可按工作方块、输入、附加、输出搜索

### 配方树

1. 点击"配方树"标签页
2. 搜索并选择目标物品
3. 选择模式：
   - **查看获取**：显示如何制作该物品（原料 → 成品）
   - **查看制作**：显示该物品的用途（原料 → 衍生物）
4. 点击"生成配方树"
5. 使用鼠标拖拽、滚轮缩放查看

### 快捷操作

- 点击任意物品/标签可弹出快捷菜单
- 将鼠标移到物品或标签上时，可按 `R` 查看获取配方、按 `U` 查看制作配方、按 `T` 查看配方树；移到物品上按 `A` 可新建获取配方，并自动将该物品填入输出槽位
- 将鼠标移到物品、标签或配方上时，可按 `W` 编辑；按 `S` 可查看物品所在标签或标签/配方详情
- 标签配方查询只匹配配方槽中明确引用该标签的配方，不包含标签内物品或父子标签的间接引用
- 输入框及其他编辑控件聚焦时快捷键暂停；不适用于当前实体的按键会被忽略
- 点击右上角的键盘图标可随时查看全部快捷键
- 配方树支持 Ctrl+滚轮缩放，Shift+滚轮平移
