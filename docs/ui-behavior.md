# 界面与权限行为

- 本地编辑模式显示保存状态、立即保存和下载备份，并允许新建、编辑、删除及迁移。
- 生产模式显示“公开只读快照”，隐藏编辑入口，快捷菜单不提供编辑，编辑快捷键不会触发。
- 工作方块物品编辑页显示默认固定费、百分比和可选上限；移出“工作方块”标签后配置保留但停止应用。
- 配方编辑页显示工作方块默认值，并可分别继承或覆盖固定费、费率和上限。
- 顶部费用计算图标位于快捷键图标左侧；两个说明弹窗打开时，全局实体快捷键暂停。
- 实体快捷键以鼠标当前悬停目标为准；数据状态重渲染后仍保留最近鼠标位置，输入控件聚焦时暂停。
- 配方树目标选择下拉允许越过控制栏边界显示；单击普通物品节点不会自动重排或重置视口，只有目标、模式、标签展开或附加物设置改变时才自动适配视口。
- 配方树默认勾选“锁定节点”，锁定时节点不可拖动；用户取消勾选后才允许手动调整节点位置。
- 配方树只显示仍存在的物品和标签；若旧数据意外留下悬空配方槽位，树会忽略该槽位，不把内部节点 ID 当作实体名称显示。
- 物品管理页在标签筛选器右侧、新建按钮左侧显示紧凑排序工具栏。主要排序和可选次要排序均支持创建时间、有效价格和标签名称，并可独立切换升降序。
- 物品排序默认采用创建时间降序；价格使用 `manualPrice ?? autoPrice`，标签使用按中文规则排序后的标签名称组合键。缺少价格或标签的物品始终置后，排序选择保存在当前浏览器。
- 物品管理页的搜索文字与标签筛选默认保留在当前浏览器；离开页面或刷新后自动恢复，清空搜索或标签即可更新保存的筛选状态。
- 窄屏下搜索框优先占满一行，筛选器、排序工具栏和新建按钮允许自然换行。
