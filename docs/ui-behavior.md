# 界面与权限行为

- 本地编辑模式显示保存状态、立即保存和下载备份，并允许新建、编辑、删除及迁移。
- 生产模式显示“公开只读快照”，隐藏编辑入口，快捷菜单不提供编辑，编辑快捷键不会触发。
- 工作方块物品编辑页显示默认固定费、百分比和可选上限；移出“工作方块”标签后配置保留但停止应用。
- 配方编辑页显示工作方块默认值，并可分别继承或覆盖固定费、费率和上限。
- 顶部费用计算图标位于快捷键图标左侧；两个说明弹窗打开时，全局实体快捷键暂停。
- 实体快捷键以鼠标当前悬停目标为准；数据状态重渲染后仍保留最近鼠标位置，输入控件聚焦时暂停。
- 配方树目标选择下拉允许越过控制栏边界显示；单击普通物品节点不会自动重排或重置视口，只有目标、模式、标签展开或附加物设置改变时才自动适配视口。
