# 裂隙维度餐厅任务链设计

## 文档说明

本文档基于 `mainline-progression.md` 的主线设计，结合 `recipe-index.json` 的真实配方数据，详细规划每个星级的任务流程、NPC剧情、商店解锁、配方解锁和功能开放节奏。

**核心设计原则：**
1. 配方解锁必须在其所有原材料和中间加工品可获取后
2. 岛屿一座一座逐个出现，每座岛完成初见任务后才出现下一座
3. 地窖是放置酒桶、发酵桶、竹匾的专用空间
4. 货架是仓库中的箱子，上菜在桌子上给坐下的顾客
5. 海带、海草、椰子等海洋食材必须渔夫岛解锁后才能获得

## NPC角色设定

### 悦灵（Ling）
- **定位**：神秘裂隙实体，与裂隙核心直接相关的能量体
- **外观**：半透明的光点聚合体，会变换颜色反映情绪
- **性格**：温和、耐心，既是引导者也是裂隙的见证者
- **剧情角色**：0星教学引导，5星揭示裂隙核心真相

### 植物学家·莉芙（Liv）
- **定位**：温柔的园艺师，热爱所有植物
- **性格**：温柔友善，对植物有深厚感情，喜欢分享种植知识
- **商店**：种子、植物食材、茶叶
- **特殊顾客标签**：植物、水果、清淡、甜、茶

### 渔夫·波特（Porter）
- **定位**：豁达的老渔夫，经验丰富
- **性格**：爽朗健谈，喜欢讲海上故事，对海鲜品质很挑剔
- **商店**：水产、海藻类食材
- **特殊顾客标签**：水产、鲜、清淡、凉爽、生食

### 猎人·艾瑞克（Erik）
- **定位**：稳重的猎人，尊重自然
- **性格**：话不多但可靠,对食材处理很专业
- **商店**：肉类、禽类、野味
- **特殊顾客标签**：肉食、浓郁、辣、烧烤

### 工匠·铁木（Timus）
- **定位**：热情的多面手工匠
- **性格**：热情开朗，喜欢制作各种工具，对餐厅建设充满热情
- **商店**：厨具、容器、装饰、建筑升级
- **特殊顾客**：不作为特殊顾客

### 集市商人·米拉（Mira）
- **定位**：精明但友善的商人
- **性格**：活泼机灵，善于发现商机，但不会坑客户
- **商店**：限量低价材料、高品质材料、轮换商品
- **特殊顾客**：不作为特殊顾客

### 魔法师·赛勒斯（Cyrus）
- **定位**：研究裂隙的学者型魔法师
- **性格**：睿智温和，对裂隙现象充满好奇，愿意帮助玩家
- **功能**：传送阵修复、裂隙研究、终局功能
- **特殊顾客标签**：甜、冷、魔法食材（后续扩展用）

## 配方解锁原则

### 工作方块解锁阶梯
| 星级 | 解锁工作方块 | 用途 |
|---|---|---|
| 0星 | 汤锅、炒锅 | 基础烹饪 |
| 1星前段 | 砧板 | 切配食材 |
| 1星中段 | 蒸笼 | 蒸制料理 |
| 1星后段 | 烤炉 | 烘焙、烤制 |
| 2星前段 | 混合碗 | 沙拉、冷菜 |
| 2星中段 | 榨汁机、茶壶 | 果汁、茶饮 |
| 3星前段 | 料理台、木棍(串制) | 生食、寿司、串烧 |
| 3星后段 | 烧烤架 | 烧烤料理 |
| 4星前段 | 发酵桶、榨油器 | 发酵品、油脂 |
| 4星后段 | 冰柜、竹匾 | 冷冻、风干 |
| 5星 | 酒桶 | 酿酒 |

### 食材解锁原则
- **0星基础食材**：稻米、鸡蛋、马铃薯、小麦、洋葱、胡萝卜、甜菜根、南瓜、西瓜、苹果、猪排、牛排、鸡肉、羊肉、兔肉、糖、盐、水桶、牛奶桶、蜂蜜瓶、油、竹子
- **1星工匠解锁**：基础容器（碗、盘、杯）、更多肉类切割品
- **2星植物学家解锁**：茶叶、番茄、白菜、生菜、草莓、浆果、菌类、更多植物
- **3星渔夫解锁**：各类鱼、水母、虾、蟹、海带、海草、椰子、睡莲
- **3星猎人解锁**：更多肉类、禽类、野味、川椒等调料
- **4星集市解锁**：高品质食材、稀有调料
- **5星魔法师解锁**：特殊魔法食材（后续扩展）

## 0 星：空岛初始

### 初始状态
**时间线**：玩家初次进入游戏

**已有设施**：
- 主岛：小型空岛，只有餐厅建筑和悦灵
- 餐厅内部：2个座位+桌子、1个厨房操作台、基础仓库（3个箱子货架）
- 厨房冰箱：1个，放入的可食物品停止腐烂
- 初始工作方块：汤锅×1、炒锅×1
- 初始容器：碗×5、盘×5
- 初始食材库存：
  - 稻米×32
  - 鸡蛋×16
  - 马铃薯×16
  - 水桶×5

**已解锁配方**：
- 米饭（汤锅：稻米 + 水桶 + 碗）
- 煎蛋（炒锅：鸡蛋 + 盘）
- 烤马铃薯（炒锅：马铃薯 + 盘）

**未开放内容**：
- 饮品和点心类订单
- 砧板、蒸笼、烤炉等其他工作方块
- 菜园、种植系统
- 传送阵、快速旅行
- 菜谱商店、NPC商店

### 悦灵教学任务链

> 
> 悦灵：「你的任务很简单：经营这家餐厅，接待来自不同维度的客人。餐厅的声望越高，裂隙就越稳定。」

- 与悦灵对话完成引导

**奖励**：无

**对话**：

> 
> 悦灵：「还有一点很重要：所有食物都会腐烂。成品保存期最短，一般1-2天就会坏掉。记得把暂时不用的食物放进厨房冰箱，可以暂停腐烂。」

**奖励**：
- 系统显示品质和腐烂倒计时UI

> 
> 悦灵：「每道菜都可以自己定价，但定太高客人会不满意，定太低你就赚不到钱。先用系统推荐价格吧。」

**任务目标**：
- 将米饭、煎蛋、烤马铃薯加入主食菜单

**奖励**：
- 解锁菜单管理功能

#### Q0-5：第一位客人

### 0星总结
- **解锁配方**：3道（米饭、煎蛋、烤马铃薯）
- **解锁工作方块**：汤锅、炒锅
- **解锁NPC**：悦灵（教学引导）
- **解锁功能**：基础烹饪、菜单设置、客人接待、声望系统
- **升星条件**：声望≥100

## 口味周系统详解

### 口味周机制

**基础规则**：
- 每周一早上6:00游戏时间刷新口味周
- 公告板显示本周受欢迎的口味标签
- 符合该标签的菜品售价×1.2、声望×1.3
- 玩家需主动查看公告板了解本周口味

**阶段演进**：
| 星级 | 标签数量 | 示例 |
|---|---|---|
| 2星 | 1个标签 | "本周流行：清淡" |
| 3星 | 1-2个标签 | "本周流行：水产+鲜" |
| 4星 | 2个标签 | "本周流行：肉食+浓郁" |
| 5星 | 2-3个标签 | "本周流行：甜+冷+水果" |

**标签池**：
- 食材标签：植物、水果、水产、肉食、米面、乳制品
- 口味标签：清淡、浓郁、甜、辣、鲜、苦、酸、咸

- 形态标签：汤羹、生食、烧烤、茶、酒

**玩家应对**：
- 查看本周口味后，调整菜单突出符合标签的菜品
- 提前准备符合标签的食材库存
- 利用口味周高声望快速升星
- 特殊顾客如果需求恰好符合口味周，奖励翻倍

## 餐厅经营系统

### 座位与接待

**座位机制**：
- 每个座位需要配套1个桌子
- 顾客入座后查看菜单，从已开放类别中点单
- 主食必点1份，饮品和点心随机（50%概率各点1份）
- 顾客等待时间：普通顾客5分钟，特殊顾客10分钟
- 超时未上菜，顾客离开且不给任何奖励

**上菜流程**：
1. 顾客坐下，头顶显示点单气泡
2. 玩家查看订单，制作对应菜品
3. 将成品放到顾客桌子上（右键点击桌子）
4. 顾客用餐（约30秒），用餐完毕结算
5. 结算：金币+声望，顾客离开

**多座位管理**：
- 同时可有多位顾客就座
- 需要合理安排制作顺序，避免超时
- 可以提前准备常见菜品库存

### 仓库与货架

**货架系统**：
- 货架本质是带UI的箱子
- 初始3个货架，可通过工匠购买扩展至40个（终局）
- 每个货架54格（标准箱子容量）
- 4星后可给货架设置冰冻模式，该货架内物品停止腐烂

**库存管理**：
- 基础食材保存期较长（7-14天）
- 中间加工品保存期中等（3-5天）
- 成品菜保存期短（1-2天）
- 酒类等特殊物品保存期很长（30天以上）
- 厨房冰箱可暂停腐烂，但容量有限

**采购策略**：
- 基础食材可大量囤积
- 成品菜尽量现做现卖
- 高品质食材优先使用（影响成品品质）
- 注意腐烂时间，及时清理过期食材

### 定价与利润

**定价机制**：
- 每道菜可自定义售价
- 系统给出推荐价格（基于成本+品质+复杂度）
- 定价过高：顾客满意度下降，可能拒绝点单
- 定价过低：利润低，但顾客满意度高

**成本计算**：
- 食材成本：所有输入材料的采购价
- 加工成本：工作方块使用磨损和能源消耗
- 容器成本：碗盘杯等消耗品（可设置是否回收）

**利润优化**：
- 使用口味周标签菜品，售价可定更高
- 特殊顾客对价格不敏感，可定价略高
- 自己种植/钓鱼/狩猎的食材成本为0，利润更高
- 高品质成品可定价更高且更受欢迎

## 品质系统详解

### 品质等级

**四个品质档**：
| 品质 | 颜色 | 售价倍率 | 声望倍率 | 获取难度 |
|---|---|---|---|---|
| 普通 | 白色 | ×1.0 | ×1.0 | 基础采购 |
| 铁 | 绿色 | ×1.3 | ×1.2 | 集市、自种自钓 |
| 金 | 蓝色 | ×1.6 | ×1.5 | 集市限量、高级种植 |
| 钻石 | 紫色 | ×2.0 | ×2.0 | 稀有掉落、完美种植 |

### 品质传递规则

**食材→成品**：
- 成品品质 = 所有输入食材品质的加权平均
- 主要食材权重更高（如"红烧肉"中猪肉权重80%，调料20%）
- 向下取整（如3个铁+1个普通 = 铁）

**品质提升途径**：
1. 购买高品质食材（集市）
2. 自己种植/钓鱼（品质随机，概率出金/钻石）
3. 使用肥料/鱼饵提升品质概率
4. 特殊事件奖励高品质食材

### 品质的影响

**对售价**：
- 高品质成品可以定更高价格
- 顾客对高品质菜品接受度更高

**对声望**：
- 提供高品质菜品获得更多声望
- 特殊顾客更看重品质

**对特殊顾客**：
- 铁品质以上才能让特殊顾客完全满意
- 钻石品质额外奖励翻倍

### 保存方法

- 笋干、腊肉等干货保存期更长

**优先级策略**：
- 短保质期食材优先使用
- 高品质食材优先冰冻保存
- 基础食材常温存放即可

**扩建菜园**（4星Q4-10）：
- 扩展至16×16格

- 解锁更多作物：草莓、浆果、茶叶、菌类、油菜等

### 种植流程

**基础步骤**：
1. 从莉芙处购买种子
2. 在菜园中翻地（右键泥土变耕地）
3. 种下种子
4. 浇水（用水桶右键或使用自动洒水器）
5. 等待生长（几分钟到几小时）
6. 收获（右键成熟作物）

**生长加速**：
- 骨粉：立即催熟（消耗品）
- 肥料箱：持续加速周围作物生长
- 特殊肥料（后续扩展）：提升品质概率

### 作物品质

**品质概率**：
- 普通种子：90%普通、8%铁、2%金、0.1%钻石
- 铁种子：50%铁、40%金、10%钻石
- 金种子：20%金、70%钻石、10%更高（后续扩展）

**提升品质**：
- 使用高品质种子
- 使用特殊肥料
- 完美生长环境（浇水及时、施肥充足）

**种子获取**：
- 基础种子：莉芙商店购买
- 高品质种子：收获高品质作物时概率掉落
- 稀有种子：任务奖励、特殊顾客奖励

- 铁钓鱼竿：缩短等待时间20%
