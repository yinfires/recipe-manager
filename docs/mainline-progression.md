# 裂隙维度餐厅主线设计稿

## 设计定位

本文件是裂隙维度餐厅的主线、群岛、NPC、星级和功能解锁维护依据。主线采用“章节群岛 + 星级纵向推进”：玩家可以在同一章节接触多座岛屿，但岛屿任务分为初见、功能、回访和特殊顾客四层，后续内容由升星或其他岛屿任务逐步开放。

世界观基于裂隙维度：玩家出生在一座空岛上，岛上只有餐厅和指引人员悦灵。裂隙会把其他维度的居民、物资和岛屿碎片带到这里。餐厅通过接待客人积累声望，声望既代表经营成功，也用于稳定裂隙。

第五星完成裂隙核心稳定任务后，进入开放式经营终局，不关闭餐厅，也不限制后续特殊顾客、收集和扩建内容。

## 关键设计原则

- 初始从 0 星开始；升星以声望达到当前上限为主，并要求完成阶段任务。
- 菜单由玩家自行决定；普通顾客只会点菜单中已有的主食、饮料和点心类别。
- 口味周在 2 星开放单标签加成，之后扩展为 2 标签、3 标签组合。
- 品质分为普通、铁、金、钻石四档。食材品质影响成品品质，成品品质影响售价和声望；具体权重另行设计。
- 所有可食物品均可能腐烂。基础材料和部分加工品保存较久，大部分成品约保存 1–2 天；酒类等特殊物品更久。厨房冰箱和后期仓库冰冻升级可以暂停腐烂。
- 岛屿出现时，主岛与该岛固定生成绳索，不限制次数、不消耗资源。各岛预埋传送阵遗迹，后期由魔法师修复为快速传送。
- 配方、标签和工作方块必须以 `public/data/recipe-manager.json` 为正式数据源，不维护第二份菜品数据。

## 初始阶段：0 星空岛餐厅

### 初始内容

- 主岛、餐厅和悦灵。
- 基础仓库、少量货架位、少量座椅和厨房摆放位。
- 厨房冰箱：放入其中的可食物品停止腐烂。
- 仅开放主食订单。
- 初始厨具：汤锅、炒锅。
- 初始基础菜：米饭、煎蛋、烤马铃薯。
- 基础食材、基础容器和最小库存。

悦灵按顺序教授采购、加工、摆盘、设置主食菜单、接待顾客、结算声望，以及售价、品质和腐烂的基本概念。

### 配方映射校验

正式 JSON 中三道初始菜的工作方块如下：

| 菜品 | 正式工作方块 | 初始用途 |
|---|---|---|
| 米饭 | 汤锅 | 基础主食教学 |
| 煎蛋 | 炒锅 | 基础主食教学 |
| 烤马铃薯 | 炒锅 | 基础主食教学 |

“烤马铃薯”虽然名称含有“烤”，但正式配方使用炒锅，因此 0 星即可使用，不需要提前解锁烤炉。后续烤炉仅用于正式数据中绑定烤炉的配方。

### 0 星不开放

- 饮品和点心订单。
- 烤炉。
- 菜园、种子和自动化农业设施。
- 稳定传送阵和快速旅行。
- 发酵、酿造、冰冻和其他高阶加工链。

## 五星主线

### 1 星：餐厅站稳脚跟

完成基础营业和声望门槛后，悦灵引导玩家接触工匠线前置。开放货架购买、仓库扩容、碗盘杯等基础容器、砧板和蒸笼，并增加座椅和厨房厨具摆放上限。

本阶段后段解锁烤炉，用于正式数据中属于烤炉的烘焙、烤包子、面包等配方；不改变烤马铃薯的炒锅归属。阶段末开放第一位特殊 NPC 顾客，并发现主岛下方的传送阵残片。

### 2 星：植物与饮品

解锁植物学家岛、菜园初级区域、种子商店、基础植物食材和种植任务；解锁饮品类别、混合碗、榨汁机和茶壶。口味周首次开放，每周随机 1 个标签获得售价和声望加成。

植物学家负责水果、茶叶、浆果、菌类和植物加工配方，并以植物、水果、清淡或甜等标签提出特殊顾客订单。菜园、肥料、洒水器和更大种植范围分阶段开放。

### 3 星：渔猎与户外加工

解锁渔夫岛和猎人岛。渔夫提供钓鱼、水产、水草、海带和椰子；猎人提供肉类、禽类、野味和烧烤材料。解锁料理台、烧烤架和串制链，开放水产、生食和烧烤相关配方。

口味周扩展为 1–2 个标签组合。渔夫和猎人均兼任特殊顾客：渔夫偏向水产、鲜、清淡、凉爽和生食，猎人偏向肉食、浓郁、辣和烧烤。

### 4 星：工坊与集市

解锁工匠岛完整功能和集市岛。工匠负责建筑、仓库、厨房、座椅、货架、容器、厨具、装饰和摆放上限；集市提供限量低价材料、高品质材料和轮换商品。

解锁冰柜、发酵桶、榨油器，开放烘焙、冷冻、发酵和油脂加工；仓库获得冰冻升级，可让指定库存停止腐烂。口味周稳定扩展为 2 标签组合。

### 5 星：魔法师与裂隙核心

解锁魔法师岛。魔法师修复各岛传送阵，开放岛间快速旅行，并解锁酒桶、完整酿造链、高阶特殊顾客和最终厨房/仓库容量。

口味周扩展为 3 标签组合。最终任务揭示悦灵与裂隙核心的关系：餐厅声望代表不同维度对同一空间的共同认可。完成裂隙核心稳定任务后，所有已解锁岛屿永久开放，进入无限经营、特殊顾客收集、品质追求和后续扩展。

## 六座功能岛

1. **植物学家岛**：种子、菜园、植物、茶叶、水果和菌类。
2. **渔夫岛**：钓鱼、水产、水草、海带和椰子。
3. **猎人岛**：肉类、禽类、野味和烧烤材料。
4. **工匠岛**：建筑、厨具、容器、货架、座椅和装饰。
5. **集市岛**：限量低价材料、高品质材料和轮换商品。
6. **魔法师岛**：传送阵、裂隙研究、快速旅行和终局功能。

每座岛按“初见任务 → 功能任务 → 星级/跨岛回访任务 → NPC 特殊顾客任务”组织。主要 NPC 同时承担商店、任务和特殊顾客身份。

## 配方与厨具解锁规则

### 三层配方池

- **悦灵教学**：米饭、煎蛋、烤马铃薯等初始基础菜。
- **NPC 商店**：常规菜谱和大部分半成品。
- **任务、特殊顾客和星级奖励**：特色菜、高阶菜和剧情菜。

简单切配和基础半成品可随食材来源自动开放；关键半成品由工匠、植物学家、渔夫或猎人任务解锁；发酵、冰冻和酿造等高阶链条需要对应厨具与任务条件。

### 厨具阶梯

| 阶段 | 主要工作方块与用途 |
|---|---|
| 0 星 | 汤锅、炒锅；米饭、煎蛋、烤马铃薯等基础主食 |
| 1 星 | 砧板、蒸笼、烤炉；切配、蒸制、烘焙和烤炉配方 |
| 2 星 | 混合碗、榨汁机、茶壶；沙拉、果汁和茶饮 |
| 3 星 | 料理台、烧烤架、串制链；水产、生食和烧烤 |
| 4 星 | 冰柜、发酵桶、榨油器；冷冻、发酵和油脂加工 |
| 5 星 | 酒桶及完整酿造链；酒饮和终局加工 |

工作方块名称和配方归属以正式 JSON 为准；不得根据菜名推断工作方块。例如烤马铃薯必须继续绑定炒锅。

## 顾客和经营规则

普通顾客最多从菜单已有的主食、饮料、点心类别中各点一份；菜单没有的类别不会被点单。特殊 NPC 顾客不直接照搬菜单，而是按标签提出三类需求。完成特殊顾客订单后，可获得食材、金钱、声望、配方、特殊材料或岛屿任务进度。

## 后续维护边界

本文件负责主线结构、解锁层级和剧情关联；售价、声望倍率、品质权重、腐烂天数、商店具体价格和每个任务的数量条件应在后续系统规格中单独确定。新增或调整菜品、标签、工作方块时，仍须遵守 `docs/food-classification.md` 和正式 JSON 的维护流程。
