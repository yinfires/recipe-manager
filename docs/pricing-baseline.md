# 基础食材定价基准

## 定价原则

- “基础食材”标签内的 85 种物品全部使用整数手动价，作为自动价格传播的外部锚点。
- 定价以获取难度为主，并按用途和常识稀有度微调。普通作物较低，肉类和水产较高，特殊植物与稀有水产最高。
- 水桶价格为 `0`，且零价是有效手动价。奶桶和蜂蜜瓶只计算内容物价值，不重复计算容器。
- 工作方块本身不设置手动物品价格，只配置每批加工费。

## 调整规范

- 修改某项基准时同步修改 `src/data/pricingBaseline.ts`，再运行 `node_modules/.bin/vite-node.cmd scripts/apply-pricing-baseline.ts`，不得只手工修改 JSON。
- 新增或移出“基础食材”“工作方块”标签的物品时，脚本会因清单不一致而停止；必须先明确其定价或加工费。
- 调整后检查成品价格分布、多层加工链和批量配方，再更新本文件和维护记录。
